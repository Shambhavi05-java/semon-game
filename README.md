# Semon Game

A browser-based memory game built using HTML, CSS, and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone this repository.
2. Open `index.html` in your browser, or use VS Code Live Server.
